# 🎭 Modular Face Parts, Outfits & Creative Character Builders

This guide lists top **Open-Source (CC0 / MIT / CC-BY)** and free modular character asset libraries, avatar generators, and 3D character engines for creating **Humans, Robots, Aliens, Monsters, and Fairy Tale / Fantasy Characters** (ranging from 2D SVG/PNG sprite layers to MetaHuman-class 3D avatar systems).

---

## 📦 Humanoid Modular Character Part Repositories

### 1. Universal LPC Raw Modular Spritesheet Parts (2D Pixel Art)
- **GitHub Directory**: [https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Generator/tree/master/spritesheets](https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Generator/tree/master/spritesheets)
- **License**: CC-BY-SA / GPL
- **Raw PNG Parts Included**:
  - `body/` — Male, female, child bodies in 8 skin tones (plus alien/orc green, pale gray, shadow tones).
  - `eyes/` — 12+ eye styles and colors (blue, green, brown, red, glowing).
  - `hair/` — 60+ hairstyles (short, long, ponytail, afro, mohawk, braids).
  - `head/` — Beards, moustaches, glasses, masks, hats, helmets.
  - `torso/` — Business suits, jackets, dress shirts, vests, hoodies, armor.
  - `legs/` — Dress pants, jeans, skirts, shorts.
  - `feet/` — Leather shoes, boots, sneakers, sandals.

### 2. Open Peeps (Hand-Drawn Vector & Raster Library)
- **Website**: [https://www.openpeeps.com/](https://www.openpeeps.com/)
- **License**: **CC0 (100% Free Public Domain)**
- **Features**:
  - Over **584,000+ possible character combinations**.
  - Separate modular layers for **Faces** (expressions, eyes, smiles, glasses), **Hairstyles**, **Torsos** (business suits, hoodies, jackets), and **Standing/Sitting Poses**.
  - Available as SVG, PNG, and Figma/Sketch component libraries.

### 4. DiceBear Open-Source Avatar Engine (Humans & Non-Humans)
- **Website**: [https://www.dicebear.com/](https://www.dicebear.com/)
- **GitHub Repository**: `dicebear/dicebear`

## 🤖 Creative & Non-Human Modular Character Builders (Robots, Aliens & Monsters)

If you are building games or applications featuring sci-fi, robotic, alien, or monstrous avatars:

### 1. DiceBear "Bottts" & "Bottts Neutral" (2D SVG Robot Engine)
- **API URL**: `https://api.dicebear.com/7.x/bottts/svg`
- **License**: CC0 / MIT
- **Features**:
  - Modular vector robot avatar generator.
  - Interchangeable robot **antennae**, **sensors**, **visor eyes**, **digital mouth displays**, **metal chest plates**, and **side bolts/gears**.
  - Full color customization (cyber neon, chrome, rusted metal, neon LED).

### 2. RoboHash Procedural Character Engine (Robots, Aliens, Monsters)
- **Website / Code**: [https://robohash.org/](https://robohash.org/) | [https://github.com/eefy/robohash](https://github.com/eefy/robohash)
- **License**: Open Source (MIT)
- **Features**:
  - Generates unique, highly detailed **Robots (Set 1)**, **Monsters/Aliens (Set 2)**, **Disembodied Robot Heads (Set 3)**, or **Kittens (Set 4)** from any text seed or hash string.
  - REST API endpoint available (`https://robohash.org/your-custom-seed.png?set=set2`).
  - Supports modular layer assembly locally via Python.

### 3. Kenney.nl Modular Sci-Fi & Robot Assets (2D & 3D)
- **Website**: [https://kenney.nl/assets?q=robot](https://kenney.nl/assets?q=robot)
- **License**: **CC0 (Public Domain)**
- **Features**:
  - Modular 2D & 3D parts: robot chassis, treads, mechanical limbs, optic visors, alien heads, and monster parts.
  - Includes raw GLTF/OBJ 3D models and layered 2D PNGs ready for modular rigging.

## 🧚 Fairy Tale & Fantasy Character Builders

For high-fantasy, fairy tale, or mythic character designs (Elves, Fairies, Wizards, Orcs, Goblins):

### 1. VRoid Studio (Free 3D Anime, Fantasy & Fairy Tale Avatar Creator)
- **Website**: [https://vroid.com/en/studio](https://vroid.com/en/studio)
- **License**: Free for commercial & non-commercial use
- **Features**:
  - Highly customizable 3D character generator for fantasy and fairy tale avatars.
  - **Fantasy Options**: Elf/pointed ears, animal ears (cat/fox/wolf), horns, wings, tails, custom hair sculpts, facial morphs, glowing eyes, magical robes, and fairy garments.
  - Exports directly to `.VRM` (open 3D avatar format), `.FBX`, or `.OBJ` for WebGL (Three.js/Babylon.js), Unity, Unreal Engine, and Phaser WebGL setups.

### 2. DiceBear "Adventurer" & "Lorelei" (2D RPG & Fantasy Styles)
- **API URL**: `https://api.dicebear.com/7.x/adventurer/svg`
- **License**: CC0 / MIT
- **Features**:
  - Hand-drawn RPG fantasy avatar generator featuring wizards, rogues, elves, paladins, and fairy tale heroes.
  - Modular options for crowns, wizard hats, elven hair, headbands, goggles, war paint, and fantasy outfits.

### 3. MB-Lab / MakeHuman Fantasy Morph Presets (Open-Source 3D)
- **Website**: [https://github.com/animate13/MB-Lab](https://github.com/animate13/MB-Lab) | [http://www.makehumancommunity.org/](http://www.makehumancommunity.org/)
- **License**: AGPL / CC0 outputs
- **Features**:

## ⚡ High-Fidelity & MetaHuman-Class 3D Character Creation Systems

For production-grade, hyper-realistic, or MetaHuman-style 3D character creation pipelines:

### 1. Epic Games MetaHuman Creator (+ Non-Human & Sci-Fi Customization)
- **Website**: [https://www.unrealengine.com/en-US/metahuman](https://www.unrealengine.com/en-US/metahuman)
- **License**: Free for use in Unreal Engine
- **Overview**:
  - The gold standard for cloud-based, photorealistic digital human creation with full facial/body rigging, LOD generation, and MetaHuman Animator support.
  - **Extending to Robots & Aliens**: While MetaHuman defaults to photorealistic humans, developers adapt MetaHuman rigs by:
    - Overriding shaders with metallic, glowing optic, or iridescent alien skin shaders.
    - Attaching modular cybernetic prosthetics, mech helmets, or alien horns via socket attachments in Unreal Engine.
    - Blending MetaHuman mesh morph targets with custom ZBrush creature head sculpts via MetaHuman DNA Calibration tools.

### 2. Ready Player Me (Cross-Platform 3D Avatar System)
- **Website**: [https://readyplayer.me/](https://readyplayer.me/)
- **License**: Free developer tier with SDKs for WebGL (Three.js), Unity, Unreal, and React.
- **Overview**:
  - Modular, cross-platform 3D character generator.
  - Includes **Cyberpunk / Sci-Fi / Robot / Alien outfits, cybernetic headgear, glowing visor eyes, and fantasy costumes**.
  - Exports lightweight `.GLB` 3D files programmatically via REST API or iframe web integration for instant browser previewing.

### 3. Reallusion Character Creator 4 (CC4) (Creatures, Aliens & Mecha)
- **Website**: [https://www.reallusion.com/character-creator/](https://www.reallusion.com/character-creator/)
- **License**: Commercial Software
- **Overview**:
  - Professional 3D character creation tool designed for humanoids, monsters, aliens, robots, and fantasy creatures.
  - Includes dynamic morph sliders for non-human anatomy, alien skin texturing, custom creature rigging, and direct export to Unreal Engine, Unity, and Blender.

### 4. Self-Hosted Generative AI 3D Model Pipelines (TRELLIS, Hunyuan3D, TripoSR)
- **Overview**:
  - Modern open-source AI pipelines allow generating custom 3D robot limbs, alien heads, or fantasy accessories on-demand from text prompts or reference images:
    - **Hunyuan3D 2.0**: High-fidelity mesh & texture generation from 2D concepts.
    - **TRELLIS 3D (Microsoft Research)**: High-detail image-to-3D mesh pipeline.
    - **TripoSR / Stable Fast 3D**: Sub-second single-image to 3D asset generator.
  - **Modular Pipeline Pattern**: Generate base meshes with AI -> Auto-rig via AccuRig/Blender -> Combine modular parts dynamically in code.

### B. Dynamic Layer Stacking for Non-Human Characters in Phaser 3

```javascript
class CreativeCharacterScene extends Phaser.Scene {
  preload() {
    // Load modular robot / alien PNG parts
    this.load.image('chassis_base', 'assets/robot/chassis_mech.png');
    this.load.image('optic_visor', 'assets/robot/visor_glowing_cyan.png');
    this.load.image('shoulder_cannon', 'assets/robot/cannon_plasma.png');
    this.load.image('mech_antenna', 'assets/robot/antenna_radar.png');
  }

  create() {
    // Stack modular non-human layers into a unified Container
    const robotCharacter = this.add.container(400, 300);

    const chassis = this.add.image(0, 0, 'chassis_base');
    const visor = this.add.image(0, 0, 'optic_visor');
    const weapon = this.add.image(20, -10, 'shoulder_cannon');
    const antenna = this.add.image(0, -35, 'mech_antenna');

    // Layer ordering (Bottom to Top: Chassis -> Visor -> Weapon -> Antenna)
    robotCharacter.add([chassis, visor, weapon, antenna]);

    // Apply interactive sci-fi pulse effect to visor layer
    this.tweens.add({
      targets: visor,
      alpha: 0.5,
      duration: 800,
      yoyo: true,
      repeat: -1
    });
  }
}
```
